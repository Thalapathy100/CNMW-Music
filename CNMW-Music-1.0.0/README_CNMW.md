# CNMW Music - Mobile Cloud Build Guide

1. Create a new repository on GitHub (via Chrome on your mobile).
2. Extract `CNMW-Music-1.0.0.zip` and upload/push the files to your GitHub repository.
3. Open the **Actions** tab in your GitHub repository.
4. Select **Build & Release** -> click **Run workflow**.
5. Wait ~6-8 minutes for GitHub's cloud server to compile the app.
6. Scroll down to **Artifacts** and download **Release-Android** (contains `cnmw_music_android_v1.0.0+1_arm64-v8a.apk` and universal APK).
